# 📊 Responsive Admin Dashboard

Nowoczesny, responsywny panel administracyjny stworzony w celu nauki zaawansowanego CSS, metodologii SCSS oraz RWD (Responsive Web Design).

👉 **Live Demo:** [Zobacz projekt tutaj](https://marcelcie.github.io/Responsive-Dashboard-SCSS/)

![Dashboard Preview](screenshot.png)
*(Tutaj pojawi się podgląd Twojej strony - instrukcja niżej)*

## 🛠 Technologie

* **HTML5** - semantyczna struktura.
* **SCSS (Sass)** - zmienne, zagnieżdżanie (nesting), mixiny, funkcje koloru (`lighten`, `darken`).
* **CSS Grid & Flexbox** - układ strony (Grid dla layoutu, Flexbox dla komponentów).
* **FontAwesome** - ikony wektorowe.

## 🌟 Główne Funkcjonalności

* **Responsywność:** Układ dostosowuje się do telefonów, tabletów i desktopów.
* **Animacje:**
    * Animacja wejścia paska bocznego (`@keyframes`).
    * Efekt "domina" przy ładowaniu ikon (opóźnienia animacji).
    * Hover efekty na kartach (uniesienie 3D).
* **Architektura SCSS:**
    * Modularny kod.
    * Użycie zmiennych dla kolorów i wymiarów.
    * Operator `&` dla stanów (`:hover`, `.active`).

## 🚀 Jak uruchomić lokalnie?

1.  Sklonuj repozytorium:
    ```bash
    git clone [https://github.com/Marcelcie/Responsive-Dashboard-SCSS.git](https://github.com/Marcelcie/Responsive-Dashboard-SCSS.git)
    ```
2.  Otwórz folder w VS Code.
3.  Użyj wtyczki **Live Sass Compiler**, aby przetworzyć plik `.scss` na `.css`.
4.  Otwórz `index.html` w przeglądarce (lub przez Live Server).
